# Schrodinger AI: A Unified Spectral-Dynamical Framework for Classification, Reasoning, and Operator-Based Generalization

This repository contains the implementation for experiments I have shown in the paper *Schrodinger AI: A Unified Spectral-Dynamical Framework for Classification, Reasoning, and Operator-Based Generalization*

The repository consists of 3 files:
- cifar.ipynb: Experiments about CIFAR10 Classifier + Surgical Rule Injection
- operator.ipynb: Experiments about model learning group operator $(a*b mod 13)$
- maze solver.ipynb: Experiments about the dual-system maze solver using both energy seeker and operator symbolic learning.
